# MMPI 해석 수련실

대학원 수련생이 MMPI-2(성인)와 MMPI-A(청소년) 프로파일을 숙련된 임상가의 사고 순서대로 해석하도록 훈련하는 학습 프로그램입니다.

- **사용하기:** 공유 링크는 운영자에게 받으세요 (로그인 필요, 공유받은 사람만 열람 가능)
- **사용 매뉴얼:** 공유 링크는 운영자에게 받으세요
- **오류 신고·제안:** 이 저장소의 [Issues](../../issues/new/choose)

> 학습용 프로그램입니다. 모든 사례는 가상 자료이고, 검사 문항은 저작권 때문에 포함하지 않았습니다. 실제 평가와 진단에 사용하지 마세요.

## 구성

| 영역 | 내용 |
| --- | --- |
| 커리큘럼 | 8단계(기초 → 타당도 → 임상척도 → 코드타입 → RC·내용·보충 → 통합 해석 → 사례 → MMPI-A) |
| 이론 | 모듈 20개 |
| 척도 사전 | MMPI-2 척도 64개 + 하위척도 31개, MMPI-A 척도(청소년 기준과 차이 포함) |
| 코드타입 사전 | 성인 39개, 청소년 10개 |
| 프로파일 분석기 | 규칙 기반 8단계 해석 엔진(MMPI-2 / MMPI-A) |
| 우리 반 (클래스 모드) | 기기 간 학습 기록 동기화, 반 통계(집계만 공개), 운영자 명단, 과제 관리 |
| 내 학습 | 영역별 숙달도, 공부한 날, 사례 점수 추이, 다음에 할 일 추천, 요약 인쇄 |
| 연구 근거 | 연구 쟁점 11개(핵심 질문, 주요 결과, 수치, 실무 적용, 오해, 논쟁, 한국 적용, 세미나 질문), 문헌 69편(DOI 확인), 사례별 근거 노트, 영상 자료와 강의 영상 대본 |
| 학습 효과 | 사전·사후 평가(평행형 A/B, 영역별 향상, 정규화 향상도), AI 채점 신뢰도 검증(ICC, Spearman, 이차 가중 카파), 반 단위 대응표본 통계와 동의자 익명 연구 데이터 |
| 실험실 | 응답 양식 실험실(무선·고정반응·과대·과소보고 시뮬레이션, 맞히기 문제), 측정오차와 코드타입 안정성(재검사 몬테카를로, 정의 수준 곡선, RCI 계산기) |
| 사례 실습 | 가상 사례 20개(성인 15, 청소년 5), 자가 점검, AI 슈퍼바이저 코칭, 모범 해석 |
| 퀴즈 | 57문항 + 간격 반복(SM-2) “오늘의 복습” + 성인 vs 청소년 O/X 12문항 |

  data-codetypes.js       성인 코드타입 사전

  data-cases.js           성인 사례 1~12
  data-mmpia.js           MMPI-A 척도·코드타입·모듈·사례·비교표
  data-extra.js           보완 모듈·코드타입·사례 17~20·퀴즈
  engine.js               해석 엔진 (MMPI.analyze)
  learning.js             학습 효과·신뢰도 계산 (SM-2, 대응표본 통계, ICC, 가중 카파 등). 순수 함수

  data-assess.js          사전·사후 평가 평행형과 AI 채점 검증용 기준 답안

  app.js                  화면(라우팅, 차트, 분석기, 사례, 퀴즈, AI 연동)
tests/
  golden.test.mjs         정답 사례(골든셋): 20개 사례의 판정 고정
  rules.test.mjs          절단점 경계값 테스트 (MMPI-2 / MMPI-A)
  data.test.mjs           콘텐츠 무결성 (id 중복, 척도 이름, 점수 범위, 필수 항목)
  learning.test.mjs       통계 함수를 문헌 예제 값과 대조(Shrout·Fleiss ICC 등), 평가 문항 무결성
  e2e/aiconnect.e2e.mjs   AI 연결 브라우저 종단 테스트(요청 복사, 개인 API 키)
  e2e/research.e2e.mjs    학습 효과 브라우저 종단 테스트(사전·사후, 복습, AI 채점 신뢰도, 연구 데이터)
  classdata.test.mjs      클래스 모드: 병합 시 기록 보존, 결과에 답안 없음, 집계, 3명 미만 숨김
  e2e/class.e2e.mjs       클래스 모드 브라우저 종단 테스트(Playwright, 플랫폼 저장소 모의 객체)
  sim.test.mjs            실험실 모듈: 엔진과 코드 규칙 일치(무작위 프로파일 4,000개), 응답 양식 방향, 시뮬레이션 성질
  fixtures/golden.json    골든셋 기대값

## 개발

Node.js 20 이상만 있으면 됩니다. 외부 패키지는 없습니다.

```bash
npm test               # 전체 테스트
npm run check          # app/*.js 문법 검사
npm run preview        # dist/index.html 생성 후 브라우저로 열기
npm run golden:update  # 규칙을 의도적으로 바꾼 뒤 골든셋 갱신
npm run bundle         # 카톡·메일로 보낼 단일 HTML 파일 생성 (dist/mmpi-academy-v<버전>.html)
npm run e2e            # 브라우저 종단 테스트 (Playwright 필요: npm i --no-save playwright@1.63.0)
```

푸시와 풀 리퀘스트마다 GitHub Actions가 문법 검사, 단위 테스트, 브라우저 종단 테스트를 실행합니다.

### 해석 규칙을 바꿀 때

1. `app/engine.js`의 규칙을 수정합니다.
2. `npm test`를 실행합니다. 골든셋 테스트가 깨지면 **어떤 사례의 판정이 바뀌었는지** 확인합니다.
3. 의도한 변화라면 `npm run golden:update`로 기대값을 갱신하고, `git diff tests/fixtures/golden.json`으로 바뀐 판정을 하나씩 검토합니다.
4. 절단점을 바꿨다면 `tests/rules.test.mjs`의 경계값 테스트도 함께 고칩니다.
5. 커밋 메시지에 근거 문헌(매뉴얼 쪽수 등)을 적습니다.

`golden.test.mjs`의 `INTENT` 표는 각 사례의 설계 의도(타당도 판정, 코드타입)를 따로 고정합니다. 골든셋을 잘못 갱신해도 여기서 한 번 더 걸러집니다.

### 사례를 추가할 때

`app/data-extra.js`(또는 새 데이터 파일)에 사례를 추가하면 `data.test.mjs`가 척도 이름, 점수 범위, 필수 필드, 모범 해석 7개 영역을 검사합니다. 그다음 `golden.test.mjs`의 `INTENT`에 의도를 적고 `npm run golden:update`를 실행합니다.

### 배포

프로그램은 호스팅 플랫폼의 공유 페이지로 배포됩니다. `app/` 폴더의 파일을 그대로 올리며, 플랫폼이 HTML 뼈대(doctype, head)를 붙이므로 `index.html`에는 본문만 있습니다. AI 기능(코칭, 통합 해석, 슈퍼바이저)은 공유 링크에서는 기본 AI로 동작합니다. 어느 버전에서나 각 화면의 “다른 AI용 요청 복사”로 다른 AI 채팅에 요청을 붙여 넣고 답변을 다시 붙여 넣을 수 있습니다.

`npm run bundle`로 만든 단일 HTML 파일은 공유 링크 밖에서 열리는 오프라인 버전입니다. 클래스 모드는 꺼지고, AI 기능은 AI 연결 설정에서 개인 API 키(Google Gemini, OpenAI GPT)를 넣으면 브라우저가 해당 AI 서버에 직접 요청해 동작합니다(키는 그 브라우저에만 저장, 사용량은 본인 계정에 청구). 나머지 기능은 인터넷 없이 동작합니다. 기록은 그 브라우저에 저장됩니다.

### 클래스 모드의 저장 구조와 권한

호스팅 플랫폼의 문서 저장소(`db`) 기능을 씁니다. 접근 규칙은 배포할 때 함께 선언합니다.

| 경로 | 내용 | 읽기 | 쓰기 |
| --- | --- | --- | --- |
| `data/users/<id>/progress` | 개인 기록 전체(답안 포함) | 본인만(소유자도 못 읽음) | 본인 |
| `results/<id>` | 성적 요약(핵심 포인트 적중 0/1, 점수, 퀴즈 정오). 답안 텍스트 없음 | 본인, 운영자 | 본인 |
| `class/summary` | 반 통계(집계값만, 학생 id 없음) | 모두 | 운영자 |
| `class/assignments` | 과제 목록 | 모두 | 운영자 |

운영자는 문서 소유자와 편집자(Editor)입니다. 학생에게는 제출 인원이 3명 이상인 항목의 통계만 보입니다. 이름은 저장하지 않고 화면에 표시할 때마다 id로 조회합니다. 학우들이 기록을 저장하려면 같은 조직 계정에 속해 있고 기여자(Contributor) 이상으로 공유받아야 합니다. 그렇지 않으면 기존처럼 브라우저에만 저장됩니다.

### 연구 윤리

`학습 효과` 기능으로 모은 데이터를 학회나 논문으로 발표하려면 소속 기관의 연구윤리(IRB) 승인이 필요할 수 있다. 프로그램은 학생 본인이 동의한 경우에만 익명 연구 데이터에 포함하고, 이름·id·답안을 넣지 않는다. 동의는 언제든 철회할 수 있다.

### 실험실 모형의 한계

`sim.js`의 응답 양식 모형은 교육용 단순화 모형입니다. 척도별 문항 수는 MMPI-2 공개 자료를 따랐지만 "그렇다" 채점 비율과 규준 평균·표준편차는 근사치이며, 실제 채점 키나 규준이 아닙니다. 점수의 정확한 값이 아니라 응답 양식에 따라 어떤 척도가 어느 방향으로 움직이는지를 보여 주는 것이 목적입니다. 재검사 시뮬레이션은 모든 척도의 SEM이 같고 오차가 독립이라고 가정합니다.

## 근거 문헌

Graham(2012), Greene(2011), Butcher 외(2001) MMPI-2 매뉴얼, Ben-Porath(2012), Friedman 외(2015), Butcher 외(1992) MMPI-A 매뉴얼, Archer(2017), Finn(2007), Jacobson·Truax(1991, RCI). 해석 기준은 이 문헌들을 요약·재서술한 것이며, 한국판 매뉴얼과 규준에 따라 다를 수 있습니다. 내용 검토는 Issues의 "내용 오류 신고"로 요청해 주세요.

MMPI-2와 MMPI-A는 미네소타 대학교의 등록상표이며, 이 프로젝트는 출판사와 관련이 없습니다.
