## 중요한 한계
- 녹화 환경(헤드리스 Chromium)에는 한국어 TTS 음성과 마이크가 없습니다. 그래서 브라우저 TTS와 음성 인식을 **모의 객체**로 바꾸고, 낭독할 문장과 인식된 말을 화면 상단 자막으로 표시했습니다. 영상은 앱의 흐름과 상태 변화를 보여 줄 뿐, 실제 음성 출력이나 인식 정확도의 증거가 아닙니다.
- 실제 기기에서 소리가 나는 것, 안드로이드 화면 잠금 중 재생, 실제 마이크 인식은 **미검증**입니다.
- AI 음성 질의응답(Claude API)은 실제로 호출하지 않았습니다(**미검증**). 영상과 기록 속 답변은 검색 기반 도우미(AI 아님)의 답변입니다.
