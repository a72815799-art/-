# 기능별 완료 상태

상태 표기:
- **완료**: 구현했고 자동 테스트를 통과함
- **부분 완료**: 일부만 구현했거나 일부 조건에서만 확인함
- **미검증**: 구현했으나 실제 환경에서 확인하지 못함
- **실패**: 동작하지 않음

자동 테스트는 모두 헤드리스 Chromium에서 실행했습니다. 실제 사람이 화면을 보며 확인한 것은 아니며, 화면 캡처를 사람 대신 개발자가 점검했습니다.
