# 제한사항 보고서

## 1. 구현하지 못한 기능
- 고품질 한국어 음성 파일(신경망 TTS)을 만들지 못했습니다. 이 환경에서는 외부 TTS 서비스와 모델 저장소 접속이 차단되어 있었고, 유료 서비스는 사용자 승인이 필요합니다. 그래서 오프라인 합성기(eSpeak NG)로 핵심 요약 음성만 만들었습니다(MP3 33개, 약 119분, 기계음).
- 외부 배포(https 주소)는 사전 승인 대상이라 하지 않았습니다. 휴대폰에서 마이크 음성 인식을 쓰려면 https나 localhost 주소가 필요할 수 있습니다.

## 2. 일부만 구현한 기능
- **오디오 파일 강의:** 핵심 요약, 시험 핵심, 혼동 주의만 담았습니다. 상세 18개 항목과 심화 이론의 연속 청취는 브라우저 TTS로만 가능합니다.
- **문제 검증:** 400문항 모두 규격 자동 검사와 AI 독립 검토를 거쳤습니다. 하지만 사람 전문가 검토와 교재 대조는 하지 않았습니다.

## 3. 테스트하지 못한 기능
- 실제 음성 출력: 헤드리스 환경에는 한국어 음성이 없어 모의 객체로 호출 순서와 내용만 확인했습니다.
- 실제 마이크 음성 인식과 그 정확도
- 안드로이드 실기기: 화면 잠금, 백그라운드 재생, 자동재생 제한, 삼성인터넷. Pixel 7 크롬 에뮬레이션만 했습니다.
- iOS Safari
- Claude API 실제 호출(비용 발생), 실제 AI 답변 품질, AI 음성 질의응답
- 사람이 직접 하는 사용성 평가

## 4. 유료 API가 필요한 기능
- AI 개인교수 자유 대화와 AI 음성 질의응답: Claude API, 사용자 키. 2026-11 공개 단가 기준 Opus 5.5는 입력 100만 토큰당 $4, 출력 $20입니다. 질문 한 번에 대략 입력 3~6천 토큰, 출력 0.5~1.5천 토큰이 들어 약 $0.02~0.05로 추정합니다(실측 아님).
- 고품질 TTS·STT 서비스: 연동하지 않았습니다.

## 5. 브라우저·기기별 제한
- 안드로이드 크롬은 화면이 꺼지거나 다른 앱으로 바뀌면 `speechSynthesis` 낭독을 멈출 수 있습니다(일반적으로 알려진 동작이며 실기기로 확인하지 않음). 대안은 두 가지입니다. ① 운전 모드의 화면 꺼짐 방지(Wake Lock)를 쓰고 거치대에 화면을 켜 둡니다. ② 오디오 파일 재생(`<audio>`, 잠금화면 조작 지원)을 씁니다.
- 일부 브라우저는 `speechSynthesis`의 pause/resume이 불안정합니다. 그래서 일시정지는 낭독을 취소하고 현재 문장 위치를 기억했다가 그 문장부터 다시 읽는 방식으로 구현했습니다.
- `file://`로 열면 마이크 음성 인식이 막힐 수 있습니다. 그 경우 아래 입력창에 명령을 입력하면 같은 흐름을 쓸 수 있습니다.
- 학습 기록은 브라우저별, 기기별로 따로 저장됩니다. PC와 휴대폰 사이 동기화는 JSON 백업과 가져오기로 해야 합니다.
- 기기에 한국어 TTS 음성이 없으면 낭독이 영어 발음이 되거나 소리가 나지 않을 수 있습니다. 안드로이드에서는 Google 음성 서비스의 한국어 음성을 설치하세요.

## 6. 콘텐츠 출처 확인의 한계
- 이 환경에서는 MSD, PubMed, NIMH, 국가정신건강정보포털에 직접 접속하는 것이 차단되었습니다. 그래서 출처 확인은 웹검색 결과 요약으로만 했고, `source_verified=true`인 경우도 **원문을 열람하지 않았습니다**.
- 국가정신건강정보포털, 국립정신건강센터 같은 국내 공공자료는 직접 확인하지 못했습니다.
- DSM-5/DSM-5-TR 원문은 열람하지 않았습니다. 진단 기준 문장은 학습용으로 새로 쓴 것이며 원문 표현과 다릅니다.
- 이론가 관련 내용 다수(Kernberg, Kohut, Mowrer, Foa, Horowitz 등)는 모델 지식으로 작성했고 `미확인`으로 표시했습니다.
- 검토 과정에서 원문 수치를 확정하지 못해 표현을 완화한 문항이 있습니다(`review_note` 필드, `reports/review/`).

## 7. 교재 미대조 사항
- 모든 콘텐츠와 문항이 `textbook_compared=false`입니다. 교재 판본, 장 번호(3판 기준 제4, 5, 6, 10장으로 알려짐), 세부 목차, 용어 번역, 교재가 강조하는 학자는 확인하지 않았습니다.
- 지속성 비탄장애(DSM-5-TR, 2022 신설)는 교재 3판에 없을 수 있습니다. 해당 단원과 문항에 이 점을 명시했습니다.
- 번역어는 교재와 다를 수 있습니다(예: Horowitz 단계 명칭, 자극 용암법, 신호불안, 성격기능 요소).

## 8. 발견된 오류와 처리
- 외상 영역 단일정답 문항의 정답이 1번에 몰려 있었습니다(49문항 중 43개). 보기를 회전해 고르게 나눴습니다(`scripts/rebalance-positions.mjs`).
- 독립 검토에서 지적된 사항(해설 오기, 단정적 표현, 모호한 채점 1건, 사례 증상 누락 1건)을 반영했습니다. 상세 내용은 `reports/review/*.json`과 `reports/review/fixes/*.json`에 있습니다.
- 테스트 중 Chromium에서 접두사 없는 `SpeechRecognition`이 우선 사용되어 모의 객체가 무시되는 문제를 발견해 테스트 코드를 고쳤습니다. 앱 코드의 결함은 아닙니다.
