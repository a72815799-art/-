📌 MMPI 해석 수련실
MMPI-2·MMPI-A 프로파일을 숙련 임상가의 사고 순서대로 해석하는 연습용 프로그램이에요.
· 이론 20개 모듈, 가상 사례 20개(성인 15·청소년 5)
· 프로파일 분석기(8단계 해석), 응답 양식·측정오차 실험실
· 사례별 모범 해석, 심화 해설, 논문 근거 노트
· 연구 쟁점 11개와 문헌 69편, 퀴즈와 복습, 내 학습 기록

📎 함께 보내는 파일
1) 프로그램(HTML 파일): 저장한 뒤 크롬이나 엣지로 열어 주세요. 휴대폰은 “다른 앱으로 열기 → 브라우저”로 열면 됩니다.
2) 사용 설명서(PDF): 화면 캡처와 함께 기능을 설명해 두었어요.

처음이면 ‘학습 효과’에서 사전 평가를 보고 ‘커리큘럼’ 1단계부터 시작하면 됩니다. 기록은 각자 브라우저에 저장돼요.

학습용이라 실제 내담자 정보는 넣지 말아 주세요. 써 보고 불편한 점이나 틀린 내용이 있으면 편하게 알려 주세요!

받은 파일 여는 방법

  1. PC: 받은 HTML 파일을 더블클릭하거나 크롬·엣지 창에 끌어다 놓습니다.
  2. 휴대폰: 카톡에서 파일을 저장한 뒤 “다른 앱으로 열기”에서 크롬이나 사파리를 고릅니다. 카톡 안 미리보기로는 일부 기능이 동작하지 않습니다.
  3. 기록: 공부 기록은 연 브라우저에 저장됩니다. 새 버전을 받으면 이전 파일과 같은 이름·위치에 덮어쓰세요.
  4. AI 기능: 오프라인 파일에서는 “AI 연결 설정”에 개인 제미나이·GPT 키를 넣거나, 각 화면의 “다른 AI용 요청 복사”로 쓰는 AI 채팅에 붙여 넣습니다.
